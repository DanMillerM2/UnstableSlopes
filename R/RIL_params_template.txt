# Parameter file for RIL.R
#
# One "keyword: value" pair per line. The order lines appear in is not significant -- every
# line is self-labeled by its keyword. Blank lines and lines starting with "#" are ignored,
# and a trailing "# comment" after a value is stripped. A value may contain a colon itself
# (a Windows drive letter, "c:\...") -- only the first colon on a line separates the keyword
# from its value, so that's safe.
#
# A handful of RIL parameters are themselves *groups* of related thresholds (RIL_input()'s
# named-vector arguments, e.g. closest_node = c(`NUM WIDTHS` = 0, `MAX RADIUS` = 250, ...)).
# Those are written on one line as comma-separated "NAME=value" pairs, e.g.:
#   hollow_gradient: PRIMARY=0.3, SECONDARY=0.25, DIF1=1.0, DIF2=0.45, MIN POLY GRAD=0.2
# Names must match RIL_input()'s own sub-names exactly (see param_specs in RIL.R); order within
# the group doesn't matter, but every name in the group must be present.
#
# dem, scratch_dir, out_RIL, and executable_dir have no default and must be set below. Every
# other keyword falls back to the default noted in param_specs (in RIL.R) -- the same defaults
# RIL_input() itself uses (the Post Mortem reference run) -- if you delete or comment out its
# line here.
#
# attribute_list (the list of per-node attributes RIL computes) is NOT set from this parameter
# file directly -- it's an R object (attribute_spec()/equation_term() calls), not expressible as
# flat text. Instead:
#   - attribute_list_file (below), when set, names a separate text file holding a standalone
#     "ATTRIBUTE LIST:" / "END LIST:" block -- see RIL_attributes_example.txt for a ready-to-copy
#     example. A mean-annual-precipitation raster, if wanted, is given there as the MEAN ANNUAL
#     PRECIP attribute's own FILE argument -- there is no separate precip_raster keyword here.
#   - When attribute_list_file is NOFILE, this script falls back to
#     TWutils::ril_default_attributes() instead -- the bare identifier/area/geometry attributes
#     only, with no precipitation-dependent chain.
