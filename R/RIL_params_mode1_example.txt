# Example parameter file for RIL.R -- MODE 1 (existing RIL input file).
#
# Mode 1 hands an already-written RIL input file straight to RIL.exe, skipping RIL_input()
# entirely -- see RIL_params_template.txt for mode 2 (build the input file from
# dem/scratch_dir/out_RIL/... parameters instead), which is the more common case.
#
# Setting input_file to anything other than NOFILE selects mode 1. Every mode-2-only keyword
# (dem, scratch_dir, out_RIL, radius, closest_node, ..., attribute_list_file) is then ignored --
# the input file already carries everything RIL needs, including its own OUTPUT RIL RASTER
# keyword (read back by TWutils::RIL() to know which raster to return) -- so this example only
# sets the two keywords mode 1 actually uses:
#   - input_file: the existing RIL input file.
#   - executable_dir: the folder containing RIL.exe. Only used as a FALLBACK here -- if the
#     input file has its own working "EXECUTABLE DIR:" line, that wins instead (see
#     TWutils::resolve_executable_dir()). This example's input file has no such line, so
#     executable_dir must be set for the run to find RIL.exe.
#
# This example points at c:\work\scratch\input_RIL.txt, a real RIL input file generated by a
# prior mode-2 run of this same script (RIL.R) against c:\work\data\cherry\elev_cherry -- i.e.
# exactly the kind of file input_file_utilities.R's RIL_input() writes, and the same Fortran
# keyword grammar (DEM:, SCRATCH DIRECTORY:, RADIUS:, ..., OUTPUT RIL RASTER:,
# ATTRIBUTE LIST:/END LIST:) RIL.exe itself reads -- not RIL.R's own "keyword: value" parameter
# file grammar. Because c:\work\scratch is a scratch directory, treat this path as illustrative:
# point input_file at wherever your own already-written RIL input file actually lives (a hand-
# edited one, or one kept from a prior RIL.R mode-2 run) rather than relying on scratch_dir
# contents persisting.
#
# Note this example's input file has no EXECUTABLE DIR: line of its own, so executable_dir below
# is not just a fallback in practice -- it's the only thing telling RIL() where RIL.exe lives.

input_file: c:\work\scratch\input_RIL.txt
executable_dir: c:\work\sandbox\channelutilities\projects\ril\x64\release\
