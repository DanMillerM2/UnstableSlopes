# Pipeline config file for run_align_pipeline.R
#
# "keyword: value" lines (same rules as ground_returns.R's and align_dtms.R's own parameter
# files -- order within a section doesn't matter, blank lines and lines starting with "#" are
# ignored, a trailing "# comment" after a value is stripped, and only the first colon on a line
# separates the keyword from its value, so a value like "c:\..." or "EPSG:2856" is safe),
# grouped under section headers: [study_area], [defaults], [ref_set], [align_set], [ref_dtm],
# [align_dtm], [ref_dsm], [align_dsm], [align].
#
# [study_area] holds clip_polygon and target_crs, which are passed to every ground_returns.R and
# mosaic_dtm.R run -- set them only there. clip_polygon NOFILE (the default) uses every LAZ, DTM,
# and DSM tile in each folder, unmasked.
# [defaults] is optional and holds ground_returns.R parameters shared by both [ref_set] and
# [align_set]; a set can repeat a keyword itself to override the shared default just for it.
# [ref_set] and [align_set] are each one ground_returns.R run (see param_specs in
# ground_returns.R for the full list of recognized keywords) and must set input_dir and
# output_dir. [ref_dtm] and [align_dtm] are each one mosaic_dtm.R run (see param_specs in
# mosaic_dtm.R) and must set tile_dir and output_dtm -- or, to skip mosaicking, existing_dtm
# alone: an already-mosaicked DTM used as-is (an ESRI GridFloat .flt, in meters and in
# target_crs; it is not clipped to clip_polygon). [ref_dsm] and [align_dsm] are optional and
# work the same way for digital surface models, with output_dsm/existing_dsm in place of
# output_dtm/existing_dtm; leave a section out (or set existing_dsm: NOFILE) for no DSM. [align] holds align_dtms.R /
# TWutils::align() parameters (see param_specs in align_dtms.R) -- do NOT set refDTM/alignDTM,
# refDSM/alignDSM, or refGrnd/alignGrnd there; they are always taken from the sections above.
#
# Every output is skipped if it already exists. After changing clip_polygon (or anything else),
# delete the outputs it affects so they're rebuilt.
