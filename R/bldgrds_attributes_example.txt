# Example attribute list for bldgrds.R's attribute_list_file parameter.
#
# This is a standalone "ATTRIBUTE LIST:" / "END LIST:" block -- the same grammar bldgrds_input()
# itself writes (see TWutils's Utilities.f90 InputFileModule::ReadList, and
# TWutils::write_attribute_list()/get_attribute_list()). Nothing outside that block is read, so
# this file can hold nothing else, or -- as here -- be a copy of just the block from a working
# bldgrds input file (Sprague River project reference run -- the same reference
# TWutils::bldgrds_default_attributes() itself reproduces).
#
# bldgrds.R reads this file with TWutils::read_attribute_list_file() and passes the result
# straight to bldgrds_input()'s attribute_list argument, so any attribute name/argument
# combination bldgrds.exe understands can be requested here, in any order, without editing
# bldgrds.R itself.
#
# NOTE: bldgrds_input() itself closes this block with "END ATTRIBUTE LIST:", not "END LIST:" --
# a real discrepancy from RIL's/ValleyFloor's own convention (see bldgrds_enforce_attributes_example.txt
# for the same discrepancy on bldgrds_enforce_input()'s side, and TWutils's own CLAUDE.md). This
# file uses "END ATTRIBUTE LIST:" to match that reference run exactly, but
# TWutils::read_attribute_list_file() accepts either spelling, so "END LIST:" would work here too.

  ATTRIBUTE LIST:
    ELEVATION:
    CONTRIBUTING AREA: OUTPUT FIELD = AREA_SQKM
    MEAN ANNUAL PRECIP: FILE = e:\prism\prism_wasp_m, OUTPUT FIELD = MNANPRC_M, UNITS = mm, REPLACE
    # Lorenson, Marcus and Roberts, 1994 (mean annual flow).
    MEAN ANNUAL FLOW: OUTPUT FIELD = MEANANNCMS, REPLACE, EQUATION
      TERM: FIELD = AREA_SQKM, COEF = 0.00537986, EXPONENT = 1.176471, FIELD = MNANPRC_M, EXPONENT = 2.062353663
    END EQUATION:
    # White, McCullough, Justice and Kelsey, 2011 (channel width and depth).
    WIDTH: OUTPUT FIELD = WIDTH_M, REPLACE, EQUATION
      TERM: FIELD = AREA_SQKM, COEF = 1.5662, EXPONENT = 0.385
    END EQUATION:
    DEPTH: OUTPUT FIELD = DEPTH_M, REPLACE, EQUATION
      TERM: FIELD = AREA_SQKM, COEF = 0.0917, EXPONENT = 0.3667
    END EQUATION:
  END ATTRIBUTE LIST:
